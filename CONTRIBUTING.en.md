# Contributing

[中文](CONTRIBUTING.md) | English

Code and bundled demos use MIT. Contribute code only if you are entitled to license it under MIT; document licenses for any additional assets separately.

Keep the tool fully offline without external requests or runtime dependencies. Preserve favorites export/import compatibility and support both interface languages. When editing a reference, keep its ID and image provenance, align Chinese/English suggested uses, and review both reusable templates. Do not replace the original generation prompt with a translation.

Run build and browser checks after changes. Record the source, creator or generation method, permission evidence and content license for new material. Do not commit private paths, accounts, keys, historical deliverables or unauthorized catalogs. Never mark untested platforms as passed.
