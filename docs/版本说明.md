# v1.0.0 · 中英双语公开版

附带原编号101—130的30项AI生成电影、写实与三维场景参考。程序、图片、说明及模板按MIT提供，以依法享有的权利为限。

界面可切换中文/English，名称、特点、用途、组合模板及使用指南均双语。语言切换保留筛选、比较、收藏与用户输入；用户输入不自动翻译，原始生成/编辑提示词保持原文。完全离线，无账号、服务器或生图接口。

原1—100号、整册PDF/MD、私人记录、未收录样板和历史包不包含。每图1254×1254原字节及来源数据保留。源码使用参数与相对路径构建，收藏可导入导出。

Mac Chrome/Edge双语功能已验证；Windows/Safari未实机验证。

## English

v1.0.0 includes 30 AI-generated cinematic, realistic and 3D references (IDs 101–130), a Chinese/English interface, bilingual descriptions and reusable templates, and an offline bilingual guide. MIT covers code and bundled demos to the extent applicable rights are held. Original image bytes and generation prompts are preserved.

Switching languages keeps filters, comparison, favorites and typed input. No account, server or generation API is required. Private material and historical archives are excluded. Tested on Mac Chrome/Edge; Windows/Safari remain untested on actual devices.
