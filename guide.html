图像风格选型台 · 使用说明

本工具附带30项AI生成参考图，帮助您看图选表现方向，再组合提示词。它完全离线运行，不连接生图服务。

1. 打开与切换语言

解压整个离线包，保留首页和images文件夹的相对位置，双击“首页.html”。右上角选择“中文”或“English”；界面、参考内容及组合模板会同步切换。只在当前浏览器记住语言偏好。

2. 搜索、筛选与比较

关键词支持中英文，多个词用空格分开，结果需同时匹配。按风格系列或用途筛选；可将2—3项加入比较，最多3项。“清除筛选”清除搜索与筛选，“清空比较”移除比较项。点击图片查看原尺寸。

3. 组合和复制提示词

点击“选用风格”，填写主体、画幅、用途、留白和避免元素。中文界面生成中文模板，英文界面生成英文模板；您已输入的内容不会被自动翻译或清空。切换时比较项、收藏和筛选保持不变；未改动的默认留白/避免文字会跟随语言切换。

点击“复制提示词”；浏览器若禁止自动复制，工具会选中全文，此时按⌘C（Mac）或Ctrl+C（Windows）。也可点击“手动选择全文”。展开来源区可核对模板和原始英文样图提示词。生成图片需将提示词复制到您选择的生图工具。

4. 收藏、导出和导入

点击卡片“收藏”，勾选“只看收藏”查看。使用“导出收藏”保存JSON，在另一目录或设备打开本工具后使用“导入收藏”合并。两种界面使用同一份收藏，原中文公开候选导出的收藏继续兼容。

收藏仅保存在当前浏览器本地，不跨设备同步；换浏览器、移动文件夹或清理数据可能导致收藏不可用。主题等输入内容不保存。请定期导出备份。

5. 内容、编号与许可

30图保留101—130号：101—120涵盖电影、写实与三维动漫，121—130为创意写实场景；名称是视觉描述。全部为AI生成，不是真实照片或电影剧照。图片保持原1254×1254规格及来源数据。

代码与随附演示按MIT提供，以依法享有的权利为限，分发时保留许可和版权声明。自备素材须单独确认许可。详见内容与来源说明。

6. 常见情况

  • 图片不显示：确认已完整解压，首页与images文件夹保持原位置。
  • 没有搜索结果：减少关键词或点击“清除筛选”。
  • 无法保存收藏：仍可在本次使用并导出JSON。
  • 开发与自备图册构建：见源码包的README。已验证Mac Chrome/Edge，Windows和Safari尚未实机验证。

Image Style Selector · User Guide

Browse 30 AI-generated references, choose a visual direction and compose a prompt. The tool runs entirely offline and does not connect to an image-generation service.

1. Open the tool and choose a language

Extract the complete offline ZIP, keep the HTML file and images folder in their original relative locations, and open “首页.html”. Select 中文 or English at the top right. Interface text, reference descriptions and reusable templates switch together. Your language preference is remembered only in this browser.

2. Search, filter and compare

Search in English or Chinese. Separate terms with spaces; every term must match. Filter by collection or suggested use. Add 2–3 items to compare, with a maximum of 3. “Reset filters” clears the search and filters; “Clear comparison” removes compared items. Click an image to open it at full size.

3. Compose and copy a prompt

Click “Use this style” and enter a subject, aspect ratio, intended use, negative-space requirement and elements to avoid. The template follows the interface language. Your own input is preserved without automatic translation. Switching languages keeps filters, compared items and favorites; unchanged default negative-space and avoidance text follows the language.

Click “Copy prompt”. If the browser blocks automatic copying, the full text is selected; press ⌘C on Mac or Ctrl+C on Windows. You can also choose “Select all text”. Expand the source section to review the template and original English image-generation prompt. Copy the result into your preferred image-generation tool to create an image.

4. Favorites, export and import

Click “Favorite” on a card and select “Favorites only” to view saved items. “Export favorites” saves a JSON file; use “Import favorites” in another folder or device to merge it. Both languages share the same favorites. Favorites exported by the earlier Chinese public candidate remain compatible.

Favorites are stored locally in this browser and do not sync across devices. Changing browsers, moving the folder or clearing browser data may make them unavailable. Subject and other input text is not saved. Export backups regularly.

5. Content, IDs and license

The references keep IDs 101–130: IDs 101–120 cover cinematic, realistic and 3D animation directions, and IDs 121–130 explore creative realistic scenes. Names describe visual approaches. All images are AI-generated, not real photographs or film stills. Their original 1254×1254 pixels and provenance data are preserved.

Code and bundled demo content are provided under MIT to the extent applicable rights are held. Keep copyright and license notices when redistributing. Check rights separately for custom material; see the content and provenance notice.

6. Troubleshooting

  • Missing images: extract the entire ZIP and keep the HTML file and images folder together.
  • No search results: use fewer keywords or choose “Reset filters”.
  • Favorites storage unavailable: favorites can still be used and exported during this session.
  • Development and custom catalogs: see README.en.md in the source package. Tested on Mac Chrome/Edge; Windows and Safari have not been tested on actual devices.
